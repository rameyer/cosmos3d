### Meyer et al. 2026 COSMOS-3D [OIII] Catalogue README

id_CWEB: ID of the source in the COSMOS-Web DR1 catalogue (Shuntov et al. 2025)

RA: RA of the source (from COSMOS-Web)

Dec: Dec of the source (form COSMOS-Web)

mean_grades: mean of the visual inspection grade. Grades are given in increments of 1 between -1 and 3 (see further paper).

median_grades: median of the grades. Only emitters with median >=1.5 are retained in this catalogue.

std_grade: standard deviation of the grades. Note that 4-5 inspections/grades are provided for each object.

tile_C3D_grizli: Number of the internal tiling system used for COSMOS-3D in the grizli pipeline. COSMOS-3D is divided in 20 tiles number X.Y with X in [1-4] and Y in [1-5].

segment_id: id of the source in the segmentation maps of COSMOS-Web (A1-10, B1-10). Cf COSMOS-Web DR1.

z: Redshift (Based on a simultaneous fit of the OIII+Hb lines

f_Hb,e_Hb: flux and error the H-Beta 4862 line [erg / s / cm^2]. -99 fluxes and errors indicate the line is not observed/measured.

f_O34960, e_O34960:  flux and error the [OIII] 4960 line [erg / s / cm^2] 

f_O35008, e_O35008:  flux and error the [OIII] 5008 line [erg / s / cm^2] 

mag_model_f444w, mag_err_model_f444w: F444W model magnitude from the COSMOS-Web catalogue, necessary to compute the full completeness for each source (see further paper).
